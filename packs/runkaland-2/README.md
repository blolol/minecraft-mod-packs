# Runkaland 2

**Runkaland** is Blolol's vanilla+ Minecraft mod pack. Based on Minecraft 26.3, it focuses on performance and quality of life features over large content additions.

## Contents

* [How to play](#how-to-play)
* [Mods](#mods)

## How to play

Installing the pack is easy using [Prism Launcher](https://prismlauncher.org/):

1. Click "Add Instance", then "Import" on the left.
1. Add a name for the instance at the top, such as "Runkaland 2".
1. Copy and paste this URL into the link field: https://github.com/blolol/minecraft-mod-packs/raw/refs/heads/main/packs/runkaland-2/prism-instance.zip
1. Click "OK", then double-click the new instance to start the game.

Each time you start the game, the mod pack will automatically keep itself up-to-date.
